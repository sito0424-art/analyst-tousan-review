# analyst-tousan-review

ブログ「アナリスト父さんの何でもレビュー」の公開素材リポジトリです。

- ブログ: https://analyst-tousan-review.hatenadiary.com/
- YouTube: チャンネル名「アナリスト父さんの何でもレビュー」（開設予定）

## 中身

- `simulators/` — ブログ記事に埋め込む対話型シミュレータ（GitHub Pages で配信）
  - `bread-break-even.html` — ホームベーカリー損益分岐シミュレータ

## ブログの運営方針

- 実際に使っている製品を、実測（騒音・電気代・所要時間・容量）と計算（損益分岐・総コスト・感度分析）でレビューする
- 計算の前提と式は、記事内にすべて公開する
- 購入先の比較や助言はしない。記事内のリンクにはアフィリエイトを含むため、各記事の冒頭に PR と明記する

## 注意

公開リポジトリです。未公開の下書きや個人情報は置きません。
